
# SVG-мастерская — журнал развития проекта

Версия приложения: 0.1  
Статус: первая опубликованная версия  
Репозиторий: svg-workshop

## 1. Назначение проекта

SVG-мастерская — интерактивная учебная лаборатория для изучения устройства SVG, чтения и изменения SVG-кода, а также исследования связи между кодом и визуальным результатом.

Основная практическая задача — освоить принципы SVG на примерах и упражнениях, постепенно применяя знания при создании векторных открыток размером 200 × 95 мм.

Проект служит:
- учебной площадкой для освоения SVG;
- пространством для безопасных экспериментов с SVG-кодом;
- системой учебных примеров, схем и практических заданий;
- местом для хранения результатов обучения.

SVG-мастерская не предназначена для замены Adobe Illustrator или создания самостоятельного универсального графического редактора.

### 3.2. Поиск по коду

Добавить поисковую строку над редактором.

Функции:
- поиск по коду и комментариям;
- поиск только по комментариям;
- подсветка найденных совпадений;
- отображение количества результатов;
- переход к следующему и предыдущему совпадению;
- переход к выбранной строке;
- поиск без учёта регистра.

Предварительное техническое решение: рассмотреть интеграцию CodeMirror.

## 4. Возможные учебные инструменты и темы

Перечень ниже — не план по превращению мастерской в графический редактор и не обязательства по реализации. Каждая идея рассматривается отдельно и может быть реализована только при соблюдении главного принципа проекта.

Возможные учебные направления:
- наглядное изменение отдельных параметров SVG с объяснением соответствующего кода;
- эксперименты с геометрическими формами и координатами;
- исследование кривых Безье и контуров;
- изучение цвета, обводки, прозрачности и градиентов;
- работа с текстом и шрифтами как с элементами SVG;
- изучение орнаментов и повторяющихся элементов;
- исследование направляющих, сеток и пропорций открытки;
- экспорт учебного результата в SVG для дальнейшей работы в Illustrator.

Функции не добавляются только ради расширения возможностей интерфейса. Сложные производственные задачи и полноценная подготовка макета остаются в профильных графических программах.

## 5. Программа обучения

1. Структура SVG, холст, размеры и координаты.
2. Геометрические формы.
3. Контуры и кривые Безье.
4. Цвет, заливки, обводки и прозрачность.
5. Текст и композиция.
6. Орнаменты и повторяющиеся элементы.
7. Создание полноценной открытки и подготовка к печати.

## 6. Правила разработки

1. **Главный принцип:** новые функции добавляем только тогда, когда они помогают изучать SVG, а не ради расширения возможностей редактора.
2. Перед реализацией каждой функции формулировать её учебную пользу: какое свойство, конструкцию или закономерность SVG она помогает понять и исследовать.
3. Если ту же учебную задачу проще и полезнее решить чтением или изменением SVG-кода, не создавать для неё отдельный инструмент интерфейса.
4. Не развивать SVG-мастерскую в сторону универсального графического редактора и не дублировать инструменты Illustrator.
5. Не усложнять приложение преждевременно.
6. Сначала изучать и проектировать, затем программировать.
7. Перед изменениями сохранять резервную копию.
8. Не нарушать работу уже реализованных функций.
9. Вносить изменения небольшими согласованными этапами.
10. Проверять каждое изменение.
11. Отделять согласованные требования от идей и предположений.
12. Сохранять возможность скачивания и переноса учебного результата.

## 8. Журнал идей
### Учебный раздел и система обучения

В версии 0.2 предусмотреть развитие раздела «Учебная программа»
в полноценную учебную базу.

Планируемые возможности:
- отдельная страница для каждого урока;
- теоретические материалы и иллюстрации;
- примеры SVG-кода;
- практические задания;
- вопросы для самопроверки;
- отметки о прохождении уроков;
- ссылки на соответствующие инструменты SVG-лаборатории.

Материалы уроков хранятся в GitHub.
Учебный журнал LEARNING_JOURNAL.md ведётся отдельно
и фиксирует фактический прогресс обучения.

Формат работы:
- занятия проводятся в переписке с преподавателем;
- практические задания выполняются в SVG-лаборатории;
- структурированные учебные материалы сохраняются в репозитории.

Новые идеи и предложения записываются сюда до принятия решения об их реализации.

Для каждой идеи указываются:
- дата;
- описание;
- предполагаемая польза;
- статус: идея, обсуждается, согласовано, реализовано или отложено.

### Визуальное сопровождение учебных материалов

Каждый учебный модуль должен сопровождаться наглядными
авторскими схемами и иллюстрациями.

Типы учебных схем:
- объясняющие схемы: координаты, оси, размеры, пропорции;
- схемы устройства объектов и геометрических фигур;
- сравнительные схемы «до / после»;
- схемы связи SVG-кода с визуальным результатом.

Требования:
- схемы должны объяснять учебный материал, а не служить декором;
- иллюстрации размещаются непосредственно рядом с соответствующими объяснениями;
- предпочтительный формат — SVG;
- схемы должны быть доступны для последующего редактирования;
- визуальные примеры должны соответствовать изучаемому коду.

Материалы хранятся в папке lessons/images
с разделением по номерам занятий.
