
# SVG-мастерская — журнал развития проекта

Версия приложения: 0.1  
Статус: первая опубликованная версия  
Репозиторий: svg-workshop

## 1. Назначение проекта

SVG-мастерская — интерактивная учебная среда для изучения SVG и создания векторной графики.

Основная практическая задача — научиться создавать векторные открытки размером 200 × 95 мм.

Проект одновременно служит:
- учебной площадкой для освоения SVG;
- онлайн-редактором векторной графики;
- личной библиотекой графических решений;
- пространством для хранения учебных проектов.

## 2. Текущая версия — 0.1

Реализовано:
- главная страница;
- боковая навигация;
- раздел учебной программы;
- SVG-лаборатория;
- редактор SVG-кода;
- окно предпросмотра;
- обновление изображения;
- восстановление исходного кода;
- скачивание SVG-файла;
- адаптация интерфейса для небольших экранов.

Технологии: HTML, CSS, JavaScript, SVG.

Публикация: GitHub Pages.

## 3. Согласованные идеи для версии 0.2

### 3.1. Комментарии и структура SVG-кода

- Использовать русскоязычные комментарии.
- Разделять код на смысловые блоки.
- Давать понятные названия графическим элементам.
- Облегчить визуальную навигацию по документу.

### 3.2. Поиск по коду

Добавить поисковую строку над редактором.

Функции:
- поиск по коду и комментариям;
- поиск только по комментариям;
- подсветка найденных совпадений;
- отображение количества результатов;
- переход к следующему и предыдущему совпадению;
- переход к выбранной строке;
- поиск без учёта регистра.

Предварительное техническое решение: рассмотреть интеграцию CodeMirror.

## 4. Перспективные направления развития

Пока не утверждены к реализации.

- Визуальная панель управления параметрами SVG.
- Инструменты для создания геометрических форм.
- Работа с кривыми Безье и контурами.

- Работа с текстом и шрифтами.

- Библиотека готовых графических решений.
- Подготовка файлов к печати.

## 5. Программа обучения

1. Структура SVG, холст, размеры и координаты.
2. Геометрические формы.
3. Контуры и кривые Безье.
4. Цвет, заливки, обводки и прозрачность.
5. Текст и композиция.
6. Орнаменты и повторяющиеся элементы.
7. Создание полноценной открытки и подготовка к печати.

## 6. Правила разработки

1. Не усложнять приложение преждевременно.
2. Сначала изучать и проектировать, затем программировать.
3. Перед изменениями сохранять резервную копию.
4. Не нарушать работу уже реализованных функций.
5. Вносить изменения небольшими согласованными этапами.
6. Проверять каждое изменение.
7. Отделять согласованные требования от идей и предположений.
8. Сохранять возможность скачивания и переноса проекта.
