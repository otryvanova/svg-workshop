# Экспериментальный SVG-редактор

Изолированная сборка на Vite + CodeMirror 6. Не заменяет основной редактор.

## Возможности
- Ручное редактирование XML/SVG.
- Живой SVG-предпросмотр.
- Видимый поиск по исходному коду.
- Перемещение окружностей с записью cx/cy обратно в исходный текст.

## Проверки
`npm test` — тесты функций обновления SVG и поиска.
`npm run build` — production-сборка Vite.
